# EarForge 🎧

Тренажер музичного слуху прямо в браузері. Без встановлення, без реєстрації (нікнейм за бажанням) — просто відкрий і тренуйся. PWA — можна встановити на телефон і грати офлайн.

## Режими

| Режим | Опис |
|-------|------|
| 🎵 Note ID | Вгадай ноту за звуком |
| 🎼 Intervals | Визнач інтервал між двома нотами |
| 🥁 BPM Tap | Вгадай темп метронома, зі своїм TAP-лічильником |
| 🎹 Key Detect | Визнач тональність за акордовою прогресією |
| 🎸 Chords | Визнач якість акорду (мажор/мінор/зменш./збільш./7-mи) |

Кожен режим має 3 рівні складності (адаптивні — підлаштовуються під точність) і власне коротке пояснення перед першим запуском.

Окрім окремих режимів:
- **📚 Сесія** — зібрати кілька режимів у одну мішану добірку раундів, з підсумком і порівнянням з минулою сесією.
- **🔁 Слабкі місця** — авто-сесія лише з того, що зараз найчастіше плутається (spaced repetition, `src/srs.ts`).
- **📖 Довідка** — статична сторінка `public/guide/` з поясненням механік і глосарієм.
- **⚡ Хаки** — `public/hacks/` з практичними лайфхаками тренування слуху.
- **🏆 Таблиця лідерів** — опційна, за нікнеймом, з опційним паролем (див. нижче).

Прогрес зберігається в браузері (localStorage), окремо на профіль/нікнейм. Інтерфейс — українською або англійською (перемикач у шапці).

## Розробка

```bash
npm install
npm run dev
```

## Збірка

```bash
npm run build
```

Готові файли з'являться в папці `dist/`.

## Архітектура (коротко)

- `src/App.tsx` — тонка обгортка (стан через `useReducer`, роутинг екранів).
- `src/constants.ts` — музична теорія (ноти, інтервали, акорди), CSS-анімації, хелпери.
- `src/i18n.ts` — переклади `ua`/`en` (UI-рядки, тексти режимів, туторіали).
- `src/audio.ts` — `useAudio()`, синтез на чистому Web Audio API (без Tone.js, свідомо — розмір бандла й стабільність на iOS Safari).
- `src/storage.ts` — все localStorage (профілі, прогрес, скіп-стан туторіалів).
- `src/srs.ts` — spaced repetition (leaky-bucket вага на відповідь), живить і "Слабкі місця", і вибір наступного питання в кожному режимі.
- `src/reducer.ts` — XP/рівні/стрік/статистика.
- `src/components/` — спільний UI (Header, Menu, Login, Leaderboard, туторіал-діалог тощо).
- `src/modes/` — по одному файлу на режим + `Session.tsx` (мішана сесія / слабкі місця) + `ModeScreen.tsx` (обгортка одиночного режиму з туторіалом і адаптивною складністю).
- `server/leaderboard.js` — окремий self-hosted Node-сервер (JSON-файл, без БД). Опційний пароль на нік: перший POST з паролем закріплює його (sha256, без солі — навмисно легковажно для чисто розважального лідерборду); порожній пароль = нік лишається відкритим назавжди.
- `public/guide/`, `public/hacks/` — статичні сторінки поза SPA-білдом, лінкуються з меню в новій вкладці.
- PWA: `public/manifest.json` + `public/sw.js` (stale-while-revalidate, `/api/` і крос-origin запити не кешує).

Деплой — під підшляхом (`/earforge/`), тому `vite.config.ts` має `base: '/earforge/'`, а будь-який fetch до API йде через `import.meta.env.BASE_URL` (ніколи не хардкодити `/api/...`).

## Хостинг

Живе на `https://mandrock-tools.duckdns.org/earforge/` — статика через nginx на Hetzner VPS,
API (лідерборд) — окремий Node-процес під pm2 (`earforge-api`, порт 4173, JSON-файл
замість Vercel/Upstash), проксі `/earforge/api/` -> `127.0.0.1:4173`.

Деплой:
```bash
npm run build
cp -r dist/* /var/www/html/earforge/
# зміни в server/leaderboard.js:
cp server/leaderboard.js /root/earforge-api/ && pm2 restart earforge-api
```
